# 🌳 Исток (istok_local)

Локальное генеалогическое приложение для ведения родового дерева.

## Описание

**Исток** — это веб-приложение для создания и управления генеалогическими деревьями. Приложение работает локально на вашем компьютере и доступно через браузер с любого устройства в вашей сети (ПК, смартфон, планшет).

## Возможности

- 🌳 Создание и управление генеалогическими деревьями
- 👥 Добавление персон с подробной информацией (ФИО, даты, места, фото)
- 🔗 Родственные связи (биологические, приёмные, супружеские и др.)
- 📅 События жизни (рождение, смерть, брак, образование, работа и др.)
- 🎨 Интерактивная визуализация дерева (Cytoscape.js)
- 👤 Многопользовательский доступ с ролями (Владелец, Редактор, Читатель)
- 📱 Адаптивный дизайн (ПК + смартфон)
- 🔒 Локальное хранение данных (SQLite)

## Стек технологий

- **Backend:** Python 3.12, Django 5.1
- **Database:** SQLite
- **Frontend:** HTML, Tailwind CSS, HTMX, Alpine.js
- **Визуализация:** Cytoscape.js
- **Тестирование:** pytest, pytest-django

## Установка

### Требования

- Python 3.12+
- pip

### Шаги

```bash
# 1. Клонировать репозиторий
git clone <url-репозитория>
cd istok_local

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Активировать виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Применить миграции
python manage.py migrate

# 6. Создать суперпользователя
python manage.py createsuperuser

# 7. Запустить сервер
python manage.py runserver
```

### Доступ
- Приложение: http://127.0.0.1:8000/
- Админ-панель: http://127.0.0.1:8000/admin/
- Смартфон: http://<IP-вашего-ПК>:8000/ (в той же Wi-Fi сети)
Запуск тестов
```bash
pytest
```
