# 🌳 Исток — Генеалогическая система (istok_local)

**Исток** — это современная веб-система для построения и исследования семейных деревьев. Позволяет хранить информацию о родственниках, визуализировать связи, отслеживать события и анализировать статистику.

![Python](https://img.shields.io/badge/Python-3.12-blue)
![Django](https://img.shields.io/badge/Django-5.1-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

---

## ✨ Основные возможности

### 👥 Управление персонами
- Создание карточек персон с полной информацией (ФИО, даты, места, фото)
- Поддержка девичьих фамилий и приблизительных дат
- Загрузка фотографий с галереей и выбором аватара
- Поиск дубликатов при создании

### 🔗 Связи между людьми
- Родители и дети (биологические, приёмные, сводные)
- Супруги (действующие и бывшие)
- Автоматическое определение братьев/сестёр

### 📅 Хронология жизни
- События: рождение, брак, развод, смерть, образование, переезд, работа и др.
- События родственников автоматически отображаются в хронологии
- **Умный развод** — автоматическое завершение брака при создании события

### 🌳 Визуализация дерева
- **Иерархическое дерево** — классический вид сверху вниз
- **Свободный граф** — интерактивная сеть связей
- **Веерная диаграмма предков** — до 6 поколений
- **Табличный вид** — список с фильтрацией

### 📊 Статистика
- Распределение по полу и возрасту
- Анализ по десятилетиям и местам рождения
- Статистика браков и количества детей
- Фильтр **"Только кровные родственники"**

### 🔍 Расширенный поиск
- Поиск по имени, фамилии, отчеству
- Фильтры: пол, статус (жив/умер), годы рождения/смерти
- Поиск по местам и культуре
- **Регистронезависимый поиск** с поддержкой кириллицы

### 🔔 История изменений (Audit Log)
- Лог всех действий в дереве
- Фильтры по действию, типу сущности, пользователю
- Фиксация IP-адреса и времени

### 👥 Совместная работа
- Роли: Владелец, Редактор, Наблюдатель
- Публичные и приватные деревья
- Уведомления о ближайших событиях (дни рождения, годовщины)

## 🚀 Быстрый старт

### Требования
- Python 3.12+
- pip
- Git

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/yalexeryal/istok_local.git
cd istok_local

# Создать виртуальное окружение
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Linux/Mac

# Установить зависимости (включая dev-инструменты: ruff и др.)
pip install -e ".[dev]"

# Создать миграции и применить их
python manage.py makemigrations
python manage.py migrate

# Создать суперпользователя
python manage.py createsuperuser

# Запустить сервер
python manage.py runserver
```

Откройте браузер: http://127.0.0.1:8000/
