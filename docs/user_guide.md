## 🚀 Начало работы

### Вход в систему
1. Откройте адрес, который вам предоставил администратор (например, `http://127.0.0.1:8000/`)
2. Введите логин и пароль
3. После входа вы попадёте на страницу **списка деревьев**

### Список деревьев
На главной странице отображаются все деревья, к которым у вас есть доступ:
- **Владелец** — полное управление
- **Редактор** — может добавлять и изменять данные
- **Наблюдатель** — только просмотр
- **Гость** — для публичных деревьев

---

## 🌳 Создание дерева

1. На странице списка деревьев нажмите **"+ Создать дерево"**
2. Заполните поля:
   - **Название** — например, "Род Ивановых"
   - **Описание** — краткая информация (необязательно)
   - **Публичное дерево** — если хотите, чтобы его могли видеть другие
3. Нажмите **"Создать"**

Вы автоматически становитесь **Владельцем** дерева.

---

## 👤 Добавление персон

### Создание первой персоны
1. Откройте дерево → нажмите **"+ Добавить персону"**
2. Заполните обязательные поля:
   - Фамилия, Имя
   - Пол
3. Дополнительные поля:
   - Отчество
   - Девичья фамилия (для женщин)
   - Дата рождения (точная или приблизительная)
   - Место рождения
   - Дата смерти (если применимо)
   - Культура / национальность
   - Заметки
4. Нажмите **"Сохранить"**

### Поиск дубликатов
При создании система автоматически проверяет, нет ли похожих персон. Если найдены совпадения:
- Вы увидите список похожих персон
- Можете выбрать **"Всё равно создать"** или отменить

## 🔗 Установка связей

### Через карточку персоны
1. Откройте карточку персоны
2. В блоке **"Ближайшие родственники"** нажмите **"+ Добавить родственника"**
3. Выберите тип связи:
   - 👨 Отец / 👩 Мать
   - 👦 Сын / 👧 Дочь
   - 💍 Супруг(а)
4. Выберите действие:
   - **✨ Создать новую персону** — создаётся новая карточка
   - **🔍 Выбрать существующую** — связать с уже имеющейся персоной

### Типы связей
- **Биологические родители** — кровная связь
- **Приёмные родители** — усыновление/удочерение
- **Сводные родители** — отчим/мачеха
- **Супруги** — действующие и бывшие

## 📅 События жизни

### Добавление события
1. Откройте карточку персоны
2. В блоке **"Хронология жизни"** нажмите **"+ Добавить событие"**
3. Выберите тип события:
   - 💍 Брак / Развод
   - 👶 Рождение ребёнка
   - ✝️ Смерть
   - 🎓 Образование
   - 🏠 Переезд
   - 💼 Работа
   - 🎖️ Армия
   - ⛪ Крещение / Венчание
   - 🏆 Награды
   - И другие...
4. Укажите дату, место, описание
5. Нажмите **"Сохранить"**

### 💡 Умный развод
При создании события **"Развод"**:
1. Появится поле **"Завершить брак"**
2. Выберите из списка активный брак
3. Укажите дату развода
4. Система автоматически:
   - Проставит дату окончания в карточку брака
   - Обновит статус супруга на "Бывший муж/жена"
   - Добавит запись в статистику разводов

## 📸 Фотографии

### Загрузка фото
1. Откройте карточку персоны
2. В блоке **"Галерея фотографий"** нажмите **"+ Добавить фото"**
3. Выберите файл с компьютера
4. Добавьте подпись (необязательно)
5. Поставьте галочку **"Сделать главным фото (аватаром)"**, если нужно
6. Нажмите **"Загрузить"**

### Управление галереей
- **★ Аватар** — сделать фото главным (отображается в карточке)
- **🗑️ Удалить** — удалить фото из галереи
- Наведите курсор на фото, чтобы увидеть кнопки управления

## 🌳 Визуализация дерева

На странице дерева доступны **4 режима просмотра**:

### 🌳 Иерархическое дерево
- Классический вид сверху вниз
- Поколения располагаются ярусами
- Удобно для анализа структуры семьи

### 🕸️ Свободный граф
- Интерактивная сеть связей
- Можно перетаскивать узлы
- Лучше для сложных деревьев с множеством связей

### 🌻 Предки (веерная диаграмма)
- До 6 поколений предков
- Круговая визуализация
- Удобно для отслеживания родословной

### 📋 Таблица
- Список всех персон дерева
- Сортировка по имени, полу, дате рождения
- Фильтрация по статусу (жив/умер)

### Управление графом
- **🔍+ / 🔍−** — увеличение/уменьшение
- **⤢** — вписать всё дерево в экран
- **Колёсико мыши** — масштабирование
- **Клик по персоне** — открыть карточку

## 🔍 Поиск

### Расширенный поиск
Нажмите кнопку **"🔍 Поиск"** в меню дерева.

Доступные фильтры:
- **Имя, фамилия, отчество** — частичное совпадение
- **Пол** — мужской/женский/не указан
- **Статус** — живые/умершие
- **Год рождения** — диапазон (от/до)
- **Год смерти** — диапазон (от/до)
- **Место рождения** — частичное совпадение
- **Место смерти** — частичное совпадение
- **Культура** — частичное совпадение

💡 **Поиск регистронезависимый** — "иванов" и "Иванов" дадут одинаковый результат.

### Результаты поиска
- Таблица с ФИО, полом, датой рождения, местом
- Клик по строке открывает карточку персоны
- Счётчик найденных персон

## 📊 Статистика

Нажмите кнопку **"📊 Статистика"** в меню дерева.

### Доступные графики
1. **Распределение по полу** — круговая диаграмма
2. **Возрастные группы** — гистограмма
3. **Десялетия рождения** — анализ по периодам
4. **Места рождения** — топ-10 городов
5. **Количество детей** — распределение
6. **Статистика браков** — средняя/макс/мин длительность, разводы

### Фильтр "Только кровные родственники"
- Переключатель вверху страницы
- Исключает супругов и их родственников
- Показывает только кровных: родителей, детей, братьев/сестёр, бабушек/дедушек

## 🔔 История изменений

Нажмите кнопку **"🔔 История"** в меню дерева.

### Что логируется
- ✅ Создание персоны
- ✅ Редактирование персоны
- ✅ Удаление персоны
- ✅ Создание/редактирование/удаление событий
- ✅ Загрузка/удаление фотографий

### Фильтры
- **Действие** — создание/редактирование/удаление
- **Тип сущности** — персоны/события/фото
- **Пользователь** — кто совершил действие

### Информация в записи
- Кто (имя пользователя)
- Что сделал (действие)
- Над чем (название сущности)
- Когда (дата и время)
- IP-адрес

## 💡 Советы и хитрости

## ❓ Частые вопросы

### Как удалить персону?
Откройте карточку → кнопка **"Удалить"** → подтвердите.  
⚠️ **Внимание:** все связи и события этой персоны также будут удалены.

### Как изменить тип связи?
Удалите текущую связь и создайте новую с правильным типом.

### Почему в статистике 0 разводов?
Развод считается только если у события "Развод" указана дата, и она автоматически проставляется в карточку брака через **"Умный развод"**.

### Как добавить фото, которое отображается в карточке?
Загрузите фото в галерею и нажмите **★ (Сделать главным)**.
